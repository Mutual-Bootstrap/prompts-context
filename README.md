# Prompts & Context

This repository contains reusable prompts, context packs and guidance that help AI systems understand and consume the architecture knowledge ecosystem.

The focus is not on storing knowledge itself, but on improving how humans and AI discover, interpret and apply that knowledge consistently.

Examples:

- AI Bootstrap Context
- Repository Context Packs
- Distillation Prompts
- Architecture Review Prompts
- Knowledge Extraction Prompts
- Prompt Libraries

If a document answers the question *"How should an AI consume and work with our knowledge?"*, it probably belongs here.
