# Prompts & Context

This repository contains reusable prompts, context packs and guidance that help AI systems understand and consume the architecture knowledge ecosystem.

The focus is not on storing knowledge itself, but on improving how humans and AI discover, interpret and apply that knowledge consistently.

## Tips

Use the [AI Bootstrap Prompt](https://github.com/Mutual-Bootstrap/prompts-context/blob/main/AI%20Bootstrap%20Prompt.md) at the start of a chat to get your LLM using the right paradigms.

Use your own private bootstrap prompts to tailor for your own individual style and circumstances.
